模块以 Spring Boot Starter 形式提供：入口为 `@EnableAntiDuplicate`，通过 `@Import(AntiDupAutoConfiguration.class)` 触发装配。

- 配置层：`AntiDupProperties` 绑定 `antidup.*` 前缀属性（开关、默认超时、策略、URL 正则列表），`WebConfig` 将 `DuplicateSubmitInterceptor` 注册到 MVC 路径匹配器。
- 请求拦截层：同时暴露 `DuplicateSubmitFilter`（Servlet Filter，优先于 DispatcherServlet，可读取已缓存的请求体）和 `DuplicateSubmitInterceptor`（HandlerInterceptor），二者逻辑一致——跳过幂等方法 → 按 URL 正则匹配 → 生成 Key → 尝试加锁 → 失败则短路返回结果。
- 可扩展点（SPI）：
  - `DuplicateSubmitStrategy`：锁实现抽象，内置 `RedisDuplicateSubmitStrategy`（默认）、`LocalDuplicateSubmitStrategy`、`JdbcDuplicateSubmitStrategy`，由 `ConditionalOnProperty(name="antidup.strategy")` 选择；未显式指定时回退到 Redis。
  - `KeyResolver` + `TokenResolver`：Key 由 token+URL+参数+请求体经 SHA1 合成，`AuthTokenResolver` 默认从认证上下文取 token，可按需替换。
  - `DuplicateSubmitResultResolver`：重复命中时的响应体构造策略，默认返回空字符串。
- 常量与异常：`Constant.IDEMPOTENT_METHODS` 定义 GET/HEAD/OPTIONS 视为幂等直接放行；`AntiDuplicateException` 用于业务抛错。
- 依赖方向：config → interceptor/filter → resolver/strategy；resolver/strategy 之间无耦合；外部仅依赖三个接口完成扩展。
