多模块 Maven 聚合工程（根 pom.xml 声明 core / admin-server / client-sdk / thread-pool-spring-boot-starter / samples 五个子模块），按职责分层：
- core：纯 POJO 契约层，定义 ThreadPoolConfig/ThreadPoolStats/事件模型及枚举，不依赖任何框架，供其他模块共享。
- client-sdk：Spring Boot Starter 形态的客户端，通过 @AsyncThreadPool/@CreateThreadPool 注解 + AOP 拦截创建/获取 DynamicThreadPoolWrapper；ThreadPoolManager 以 ConcurrentHashMap 维护池注册表，并暴露 PoolLifecycleListener 供 Micrometer binder 等扩展；当 thread.pool.remote.enabled=true 时装配 RemoteConfigSourcePoolManager，由 ConfigPollingService 长轮询 Admin Server，经 NodeManager + FailoverRouter + CircuitBreaker 选择后端节点，支持 single/cluster 两种模式与多种 RoutingStrategy。
- admin-server：独立 Spring Boot 应用（ThreadPoolAdminServer 入口），内置 Web MVC + MyBatis-Plus + Caffeine/Redisson 缓存，提供用户/ApiKey/操作审计/配置快照/统计面板等 REST API，静态 HTML/CSS/JS 资源位于 resources/static；存储层通过 storage.*Storage 接口抽象，默认 MyBatis 实现，同时提供 CacheService 做缓存旁路。
- thread-pool-spring-boot-starter：仅聚合 client-sdk 对外发布 starter artifact。
- samples：sample-local（本地模式）与 sample-cs-client（CS 模式）两个演示应用。
依赖方向严格单向：admin-server → core；client-sdk → core；starter → client-sdk；samples → client-sdk/admin-server。
