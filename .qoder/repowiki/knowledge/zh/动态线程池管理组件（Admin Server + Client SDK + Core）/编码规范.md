- Bean 装配统一在 *AutoConfiguration 类中完成，并使用 @ConditionalOnProperty / @ConditionalOnBooleanProperty / @ConditionalOnMissingBean 组合控制启用开关与覆盖策略。
- 配置对象采用 Lombok @Data + 包级构造器 + 内部 Builder 模式，并在 build() 中补齐默认值（如 threadNamePrefix 回退到 poolName、maximumPoolSize 回退为 core*2）。
- 并发安全的关键集合统一使用 ConcurrentHashMap / CopyOnWriteArrayList，对 computeIfAbsent/compute lambda 内禁止结构性修改 map 或触发回调，避免 JDK 9+ IllegalStateException 与死锁。
- 异常体系集中在 exception.* 包下，每个业务异常对应一个具体子类并由 GlobalExceptionHandler 统一映射为 ApiResponse。
- 存储访问通过 storage.*Storage 接口抽象（如 ConfigStorage、StatsStorage），默认 MyBatis 实现命名约定 MyBatis*Storage，便于替换为缓存或其他持久化方案。
