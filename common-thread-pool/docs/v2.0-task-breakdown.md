## 关键约束与风险

| 约束 | 说明 |
|------|------|
| **T-15 + T-17 必须同版本发布** | 🅰 侧 tombstone 和 🅲 侧 diff+revert 语义配对，单侧上线会导致行为不一致 |
| **T-09 影响 T-15** | `ConfigAdminService` 事务保护先做，否则 `deleteConfig` 加 `triggerListeners` 后回滚行为不确定 |
| **T-05 可独立验证** | `StatsAlertService` 纯后端计算，先写单元测试覆盖，前端 T-12 只做展示 |
| **T-11 表结构变更** | `thread_pool_stats_daily` 表需要 DBA 评审，确认索引和分区策略 |
| **T-04 需确认** | `@Profile("local")` 对 mock 端点的限制需在 `application-db.yml` 中确认 profile 名 |
